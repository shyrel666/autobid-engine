## 配置与兼容规则

1. 凭据优先级：本配置加密保存的 Key > `api_key_env` 对应环境变量。接口永不返回明文/密文，仅返回是否配置及末四位提示。空输入保留旧 Key，清除使用独立动作。真实密钥不得进入仓库、测试、报告或日志。
2. UI 保存的 Key 使用 AES-256-GCM 加密入库。主密钥由 `AUTOBID_LLM_MASTER_KEY`（base64 的 32 字节）提供；未设置时使用 `AUTOBID_LLM_KEY_FILE`（默认 `data/llm-master.key`，首次保存生成，已忽略）。备份/迁移数据库时须一并安全保管该文件；丢失或更换主密钥时明确报错，不静默改用环境 Key。
3. 增补配置的租户及操作人字段；当前租户固定 default。配置更新在下次模型调用生效；已发出的请求保持原快照。旧配置和项目配额链保留，迁移选取原排序首个启用全局配置作为默认；已有安装保留原故障转移行为，新库轮询默认关闭。
4. 选择顺序：Agent 绑定 > 项目显式配额链 > 全局默认。全局轮询开启时默认配置优先，其余 priority 降序，同优先级轮转；专用配置不加入全局池。绑定兜底默认关闭；项目配额链耗尽不隐式跳到全局池。
5. 重试分建连、空响应、未交付输出前的安全重试、熔断、Worker 续跑。0=继承，-1=关闭，正数=次数；间隔 0=内置退避。不得重放已交付的正文或工具调用，实际网络尝试保持审计与 token 记账。
6. 保留 `window_tokens`（token 单位），UI 可换算 K；0=默认 200K。会话压缩保留最近完整工具交互与当前输入，摘要沿原模型调用链计量；不可压缩时明确报错。输出上限与窗口独立，章节写作跟随模型配置。
7. 连接测试使用当前表单的协议、思考、输出上限、代理及流式参数；有时限且不执行长重试。成功必须有实际内容；无调用记录显示“未测试”，不能标成“正常”。
