# S7 一体交付验收记录（E 级，本机）

验收日期：2026-11-10。对应 [AGENT_TOOL_SKILLS_PLAN.md](../AGENT_TOOL_SKILLS_PLAN.md) 第 8.1 节 S7 行、第 9~11 节；收口摘要在该计划 12.11。运维步骤见 [OPERATIONS.md](OPERATIONS.md)，组件版本见 [LOCAL_RUNTIME.md](LOCAL_RUNTIME.md)。

本记录只证明工程实现（E）。所有浏览器验收的模型都是脚本替身（`web/e2e/stub_llm.py`），不代表真实模型的写作或核验质量；业务效果与生产启用（V / P）没有验证。

## 1. 声明范围

业务用户只用浏览器即可完成下列流程，不需要安装任何程序：

- 新建项目，上传招标原件，解析为候选，对照原件采用或拒绝；扫描页经本机 OCR 识别，结果标明未经人工核验。
- 提取要求，核对否决项，作出投标决策，确认要求清单。
- 录入企业资信、业绩和证明原件，绑定要求并评估可采性；录入并确认承诺与报价。
- 生成、提交并批准大纲；编写故事板，由另一位评审人批准；人工撰写（含受控引用）或派发 AI 撰写；写作核验后由非作者定稿。
- 生成并渲染章节图表，运行响应矩阵与一致性核验，导出门禁通过后提交严格最终稿（DOCX + PDF，WPS 真实刷新目录），在页面下载。
- 查看运行能力、版本与后台作业；断线、刷新、服务重启后状态从数据库恢复。

**首版解析范围只含招标文件。** 知识库增强解析（S5b）与企业证明材料 OCR 候选（S5c）没有实施：知识库上传的扫描件不经候选核对、识别结果直接入库（页面已提示）；证明材料只留存原件，不做识别。页面和 Agent 都不提供这两类来源的解析提交。

不在范围内：可信身份与角色权限（R2 / Phase 7）。“当前操作人”只是审计声明，粉队 / 红队的作者分离按它判定，可以被伪造；因此 Agent 导出入口（`AUTOBID_AGENT_EXPORT_ENABLED`）保持关闭。

方法：

- 浏览器套件由 Go 测试（`e2e/`）启动**真实服务进程**，连接新建的隔离库，使用真实 WPS、Mermaid 与 PaddleOCR；只有语言模型是替身。
- 全流程套件 `s7-flow` 与真实招标套件 `s7-real` 的业务操作全部在页面上完成，接口只用于配置替身模型和断言读取。其他套件用接口准备数据、直接调用接口核对拒绝码，再在页面上核对用户看到的状态与提示。

- S7 套件的浏览器会话记录全部请求，访问本机以外的地址即判失败；页面未捕获的错误同样判失败。
- 所有真实文档引擎用例经 `export/officetest` 文件锁串行运行。

## 4. 验收中发现并修正

S7 联调发现的问题都在本阶段修正，并加了回归测试或浏览器断言：

- **页面与接口字段不一致**：
  - 上传时勾选“自动拆解招标目标”从不生效：页面以表单 / JSON 字段提交 `bootstrap_goals`，服务端只读查询参数。即使拆解了，接口返回 `goal_decomposition`，页面读的是 `goals_bootstrapped`，目标字段也对不上（`code` / `extract` 对 `goal_code` / `extract_result`）。现在两种提交方式都生效，拆解失败时返回说明，文档仍导入。
  - 故事板要点的字段与服务端不同（页面用 `requirement_id`，服务端是 `requirement_code` + `scoring_point`）。
- **写作门禁在页面上走不通**：新项目默认开启写作门禁，但页面不能编写故事板，章节既不能写也不能派发 AI。新增故事板编写、提交、批准与退回，受控引用插入和写作核验按钮；故事板未通过评审时页面禁止派发。
- **证据与承诺无处录入**：证据页只能查看。新增资信、业绩、证明原件（新增 multipart 上传路由）、要求绑定、承诺与报价的录入。
- **中文操作人名让请求整体失败**：请求头只能是 ASCII，页面改为百分号编码，服务端解码。
- **导出阻断项显示“未知”**：D2、D3、材料与来源相关的阻断没有标签和修复链接。已补齐，并加契约测试防止以后再漏。
- **写作门禁的错误码直接显示给用户**：改为说明怎么处理的业务文字。
- **旧程序连上已升级的库会静默改写约束**：演练实测旧程序能正常启动、不报错，却重放旧版建表脚本，改写了 3 个函数与 1 个触发器（`export_jobs_immutable`、`fixed_file_job_audit`、`return_terminal_intent_inputs` 及触发器 `trg_return_terminal_intent_inputs`），其中包括保护导出快照的 `export_jobs_immutable`。新增单调代际号 `schema_version.generation`，本版本之后的程序拒绝连接更新的库；更早的程序没有这段检查，所以回退只能恢复备份。
- **关闭材料处理后在途作业永远不结束**：没有执行器领取，已排队的解析作业到了截止时间也不会结束，等待它的 Agent 意图要挂到任务超时。现在关闭时改跑 `filework.Sweeper`，按原截止时间与尝试预算结束作业并唤醒意图。
- **关闭材料处理后页面只剩一句“未启用”**：必需材料清单仍会阻断导出，在途作业也看不到。现在照常显示两者，材料可改为非必需，作业可取消。
- **技能目录总是列出全部技能**：服务器没有开放的能力（材料处理、Agent 导出）在技能描述和 `tool_runtime_status.features` 中标明不可用。
- **运维检查把暂停的项目当在途工作**：暂停的项目没有在途工作，改为只作提示，否则有长期暂停项目时检查永远不通过。
- **既有浏览器套件过期**：S5a / S6 改了页面文案与默认值（候选模式默认开启、模型列表控件），`file-processing`、`model-settings`、`scenarios` 已同步。

## 5. 边界（未包含在 S7）

- 解析范围只含招标文件，S5b / S5c 未实施。
- 模型是脚本替身。写作、核验、检索的业务质量都没有结论。
- 没有可信身份与角色权限，“当前操作人”可以伪造；Agent 导出入口保持关闭。
- 没有做真实断网演练。验收确认了页面不访问本机以外的地址、模型不可达时检索退回全文，但没有拔网线。
- 没有长时间运行与负载测试；文档引擎同一时间只处理一个文档。
- 升级演练的历史数据是合成的（经旧程序公开接口创建），不是生产备份。
- 回退保护只覆盖本版本之后：更早的程序没有代际检查，回退只能恢复升级前的备份。
- 真实招标验收只用了开发集文件，只到大纲批准；这些文件在编写规则时已被查看，不能作为独立评测。
