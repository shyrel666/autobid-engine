## 3. 实际交付（按阶段）

- **U1 设计基础与框架**：`index.css` 语义变量（slate 色阶映射为中性灰）；`components/ui.tsx` 统一按钮 32/28px、输入 32px、Badge 带圆点、卡片 14px、焦点环、loading 保持宽度、`Drawer`、`Menu`、`ConfirmProvider`（替代全部 `window.confirm`）、对话框焦点约束/恢复与 Esc 栈、带 `dirty` 的关闭保护；`components/layout/AppShell.tsx` 272/64px 侧栏、8px 外边距主容器、48px 顶栏、<768px 抽屉、折叠偏好记忆、Ctrl/Cmd+K 快捷跳转（只检索页面与已加载项目）、服务连接与令牌入口。删除 `RoadmapPage.tsx` 与“规划中/Phase”标签。
- **U2 路由、列表与概览**：`lib/routes.ts`（纯函数，单测）+ `lib/router.ts`（pathname+search+hash 订阅、push/replace、离开保护覆盖应用内导航与浏览器后退/前进、`linkProps` 保留 Ctrl/中键新窗口）。旧地址全部按第 4.3 节 replace 跳转，未知路径/非法 ID 显示不存在页。项目列表（客户端搜索/状态/排序/分页，地址同步，“已加载 N 个项目”，更多操作菜单含删除确认）、新建表单分“基本信息/高级运行配置”、运行超时与投标截止分开。`TaskWorkspaceProvider` 同任务内保持挂载、单一 SSE、资源失效矩阵（`resources.ts`，第 7.3 节）、重连与聚焦重读。项目标题（147px）与六组一级 + 紧凑二级导航。项目概览（`progress.ts` 派生 + 下一步建议 + 导出门禁）。令牌变更不再重挂载页面（草稿不丢），`useAsync` 丢弃卸载/过期响应并在令牌变更后重读。
- **U3 招标解读与大纲**：招标包文件列表 + 解析片段详情（`?doc=&chunk=` 定位，标注“解析原文片段”，导入改为对话框）；要求与否决项页整合投标范围、否决项（保留依据必填）、评分核对、提取结果摘要（不自动确认）、`filter`/`requirement` 定位、原文位置直达、证据选择器替代手填证据 ID、文件效力“部分实现”说明；大纲页版本选择（区分“当前批准”与“正在修订”）、`version`/`requirement` 定位、未映射修复入口、派生新版本提示、编辑器关闭保护。原 `ProposalTab.tsx` 中尚未提交的 D1 改动（否决项类别、不投分包、`veto_items`、投标范围卡片）已全部迁入新页面，`VetoPanel.tsx` 原地保留并只增加定位与可访问名称。
- **U4 写作与证据**：三栏/两栏/单栏按实际内容宽度切换（1120/800 阈值，`ResizeObserver` + 同步测量）；`writing/:sectionId` 深链，缺省章节 replace 补全；`rev`/`panel`/`evidence`/`compare` 查询参数；安全 Markdown 预览（不渲染 HTML、危险链接降级为文本）；草稿状态（未保存/保存中/已保存/基线落后/冲突候选稿）；离开、AI 派发、批准、回滚前必须先处理草稿（保存/放弃/继续编辑）；409 候选稿可并排/逐行对比，可显式“以最新为基线重新编辑”，不自动重试；`beforeunload` 提示；内存草稿仓库按任务+章节隔离、不写 localStorage；证据面板区分核验状态与支持关系、缺失/失效/矛盾，来源详情抽屉按 `source_domain` 分流并保留数值指标核验；图表卡片原样保留。
- **U5 核验与导出**：响应矩阵、一致性、导出均为独立地址；矩阵两层统计、未映射/未核验/未通过/已失效/负偏离筛选、行跳要求与章节、`requirement`/`section` 定位；一致性 `run`/`finding` 定位、冲突两侧链接章节、处理方式含义说明、409 时提示“已变更或已失效”并重读、不重放；集中维护的阻断跳转表（`blocker-links.ts`）用于概览、矩阵、一致性与导出页；422 后以服务器新门禁覆盖并保留格式与模板；仅在有排队/执行任务时轮询；“导出成功≠签章/提交”说明。
- **U6 执行工作台与其余页面**：`features/execution/ExecutionPage.tsx` 实现“选择工作 → 对应活动 → 展开工具详情 → 发送引导”：288px 工作列表（按 overview 分组、`work` 参数、未知 ID 用 `api.node` 校验归属与类型）、仅按 `node_id` 精确过滤活动、`kind` 过滤（replace）、条目稳定 key（连接代次+本地序号）、按工作保存滚动位置与展开项、“有新活动”提示、连接/丢弃/缓存上限/重连提示、运行中“引导”与暂停“发送并恢复”、按任务+工作隔离草稿、在途禁止重复提交、取消需确认；有界推演摘要移入抽屉。模型配置改为 336px 列表 + 表单（切换/离开未保存保护、高级字段折叠、Agent 绑定保留）。工具调用审批区分业务审批并处理 409/410。企业资信库、知识库套用新框架与确认对话框。
