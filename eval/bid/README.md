# D0 公开语料（2026-10-29）

[`corpus.json`](corpus.json) 登记了 `ccgp_2026-10-06/` 中 10 个项目的来源、哈希和公开结果。招标文件原件仍在被 Git 忽略的目录中；评审专家名单和经办人联系方式不入库。评测规则见 [`PROTOCOL.md`](PROTOCOL.md)（草案，待冻结）。

## 这批公开材料能证明什么

| 判据 | 覆盖范围 | 能证明 | 不能证明 |
| :--- | :--- | :--- | :--- |
| 招标公告中的截止时间 | 10 个项目 | 截止时间抽取的工程回归 | 独立的抽取准确率：编写规则时已看过这 10 份文件的截止语句，保留集须另取 |
| 更正公告、废标后二次招标 | P08、P07 | 系统是否按发布先后确定效力 | P08 修改后的评标标准未公开，无法核对内容 |
| 结果公告里的逐家得分表 | 重庆 4 个项目（5 个包），每包 3 家 | 评分表抽取出的技术 / 商务 / 价格分组权重是否与实际得分相容；真实技术分的分布 | 我们生成的标书能得几分（没有这些投标文件） |
| 中标公告里的中标人总分 | 中央 / 河南 4 个项目 | 中标总分水平 | 分项得分、未中标人得分 |
| 废标公告 | P07（及杭州一例） | 确有投标人在资格 / 符合性审查中被淘汰 | 具体是哪一条否决项导致无效 |

逐家的投标无效原因按 87 号令第六十九条只告知该投标人本人，结果公告中通常不公开。O1 的逐条原因判据只能来自合作企业自己的无效记录，或财政部门公布的投诉处理决定和指导性案例。
