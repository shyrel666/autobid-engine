## 3. 已知基线边界

- 语料全部是**输入侧**公开招标文件，没有任何投标文件、评标结果或企业证明材料。
- 语料中没有 XLSX、CSV、TSV、ZIP 招标包；F0 的复杂表格与压缩包样本全部是合成工程样本。
- 解析成功不等于要求提取正确：Phase 5 的提取仍是启发式规则，必须人工复核确认。
- 当前解析器对 `.csv` 会按无 NUL 文本兜底、对 `.xlsx` 返回不支持、对以 Store 方式收入的 `.zip` 可能误判为 DOCX；这些正是 F1 要修正的基线缺口。
